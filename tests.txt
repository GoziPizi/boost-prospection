TESTS BOOST-PROSPECTION
======================

Avant chaque série : /reload-plugins
Cocher [x] quand le test est bon, noter ce qui cloche en dessous.


PROSPECTER (une entreprise)
---------------------------

[ ] 1. Entreprise dont le site n'existe pas
       Attendu : arrêt, raison « site introuvable ou incertain ». Rien dans HubSpot.

[ ] 2. Entreprise qui existe mais sans site
       Attendu : arrêt propre avec une raison claire. Rien dans HubSpot.

[ ] 3. Entreprise « normale » (ex : TYLS CAEN)
       Attendu : transaction + contact créés dans le bon pipeline et la bonne étape.
       Noter le temps : ______

[ ] 4. Entreprise déjà dans HubSpot (relancer le test 3)
       Attendu : arrêt, raison « déjà dans HubSpot ». Aucun doublon créé.

[ ] 5. Entreprise sans dirigeant sur son site
       Attendu : le nom est trouvé via LinkedIn, ou arrêt « dirigeant introuvable ».

[ ] 6. Dirigeant trouvé sans email, Apollo activé
       Attendu : email récupéré via Apollo, crédits annoncés dans le récapitulatif.


PROSPECTER-LOT (fichier CSV)
----------------------------

[ ] 7. Batch sur 5 entreprises avec CSV d'entrée
       Attendu : fichier _suivi.csv créé à côté du CSV, 5 lignes, s'ouvre bien dans Excel
       (colonnes séparées, accents corrects).

[ ] 8. La même, en interrompant au milieu (Échap), puis relancer
       Attendu : « X déjà traitées, je reprends à la suivante ». Aucune entreprise traitée deux fois.

[ ] 9. CSV sans colonne de nom reconnaissable
       Attendu : le skill montre les colonnes et demande laquelle utiliser.


CONFIG ET CONFIRMATIONS
-----------------------

[ ] 10. Question « sans confirmation » répondue Oui
        Attendu : aucune confirmation HubSpot jusqu'à la fin de la session.

[ ] 11. Question « sans confirmation » répondue Non
        Attendu : confirmation avant chaque ajout ; un refus arrête cette entreprise seulement.

[ ] 12. Config absente (renommer config.md), lancer prospecter
        Attendu : demarrer se lance, puis prospecter reprend.

[ ] 13. demarrer avec une config existante, modifier seulement le pipeline
        Attendu : le reste de la config est inchangé.
